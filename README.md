# Мой сайт-резюме

Одностраничный персональный сайт-резюме. Рекомендую кликнуть по логотипу при просмотре ^^

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

## Проверка сборки

```bash
npm run build
```
